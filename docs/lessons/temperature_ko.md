# 수업: 온도 측정과 누락 데이터

[English](temperature.md) · [확장 설치와 준비](../../README_ko.md) · [다음: 네오픽셀](neopixel_ko.md)

## 목표와 준비

약 30~40분 활동입니다. 온도 변화를 기록하고, 정상 측정값과 오류값을 구별하며, `if` 조건의 의미를 설명합니다. 활동 전에 단위와 영하 온도를 소개합니다.

micro:bit V1 또는 V2, EZMAKER 쉴드, 호환 **DS18B20 모듈**, 연결 케이블, MakeCode를 사용할 컴퓨터를 준비합니다. 설치 안내에 따라 확장을 추가합니다. 모듈의 일반 전원 배선과 데이터 풀업을 사용하며, 센서 단품을 쓰면 적절한 외부 배선이 필요합니다.

전원을 끄고 모듈의 **데이터 신호를 P13**에 연결합니다. 전원·GND는 모듈 설명서를 따르고, 이 활동에서는 포트 하나에 센서 하나를 연결합니다. 전자부는 건조하게 유지하고, 프로브를 손으로 가볍게 따뜻하게 하는 정도로 관찰합니다.

## 프로그램

새 프로젝트에서 이 예제만 사용합니다. A는 측정을 요청하며 숫자 스크롤에는 시간이 걸립니다.

```blocks
input.onButtonPressed(Button.A, function () {
    let temperature = ezmaker.readDS18B20(EZMakerDigitalPin.P13)
    // 영하도 정상 온도이므로 0 미만 전체가 아닌 정확한 오류값을 검사합니다.
    if (temperature === -999 || temperature === -273) {
        serial.writeValue("sensor_error", temperature)
        basic.showString("ERR")
    } else {
        serial.writeValue("temperature_C", temperature)
        basic.showNumber(temperature)
    }
})
```

`-999`는 센서 통신·측정 실패, `-273`은 지원하지 않는 포트 인자입니다. 둘 다 측정 온도가 아닙니다. 정상값은 소수점 둘째 자리로 반올림하지만 표시 자릿수가 센서 정확도를 뜻하지는 않습니다. 센서 오류를 포함한 읽기 결과는 1초 동안 캐시합니다.

## 관찰과 기록

1. 보드에 내려받고 A로 실내 온도를 읽어 °C 단위와 함께 기록합니다.
2. 프로브를 손으로 가볍게 따뜻하게 한 뒤 측정합니다. 요청 사이를 2초 이상 두고 세 번 이상 기록합니다.
3. 손을 떼고 실내 조건으로 돌아가는 변화를 관찰합니다.
4. 보드 전원을 끄고 모듈을 분리합니다. 전원을 다시 켜고 A를 누르면 `ERR`, 시리얼 `sensor_error`에는 `-999`가 나타나야 합니다.
5. 전원을 끄고 모듈을 재연결합니다. 다시 켜고 측정하면 정상값으로 회복되어야 합니다.

| 조건 | 측정값 또는 오류값 | 단위·상태 | 관찰 내용 |
|---|---|---|---|
| 실내 조건 | | | |
| 프로브를 따뜻하게 함 | | | |
| 식어 가는 프로브 | | | |
| 모듈 분리 | | | |
| 모듈 재연결 | | | |

시리얼에는 `temperature_C`와 `sensor_error`를 구분해 출력합니다. 오류는 매우 낮은 온도가 아닌 누락 데이터로 기록합니다. 실내 온도의 정확한 숫자는 환경과 프로브에 따라 다릅니다.

## 질문과 확장

- `temperature < 0`으로 오류를 판단하면 왜 잘못되나요?
- 센서 변환 시간·1초 캐시·화면 표시 시간은 각각 무엇인가요?
- 같은 조건에서 세 번 측정했을 때 차이가 생기는 이유를 생각해 봅니다.
- 오류를 먼저 검사한 뒤에만 온도 기준을 비교하는 알림기를 설계합니다. 단위와 기준 선택 이유를 설명합니다.

## 예상과 다를 때

`-999`가 계속되면 센서 모델·P13 신호·전원·GND·모듈 풀업 구성을 확인합니다. 숫자 표시가 끝난 뒤 A를 누릅니다. 시뮬레이터의 DS18B20은 예시값 32.6 °C를 반환하므로 따뜻하게 하기·분리 활동은 실제 보드에서 진행합니다.

V1·V2 드라이버 검증은 [TEMPERATURE_TESTING.md](../../TEMPERATURE_TESTING.md), 오류·캐시 회귀 검사는 [TESTING.md](../../TESTING.md)에 있습니다.
