# 수업: 외부 밝기 센서 관찰하기

[English](light.md) · [확장 설치와 준비](../../README_ko.md) · [다음: 온도](temperature_ko.md)

## 목표와 준비

약 30~40분을 기준으로 학급 수준에 맞게 질문을 조정합니다. 아날로그 신호를 반복 측정하고, 고정 눈금으로 표시하며, 여러 관찰값을 근거로 설명하는 것이 목표입니다. 이 비교 활동에서 센서를 교정할 필요는 없습니다.

micro:bit V1 또는 V2, EZMAKER 쉴드, 호환 아날로그 밝기 모듈, 연결 케이블, MakeCode를 사용할 컴퓨터를 준비합니다. 설치 안내의 저장소 URL로 확장을 추가합니다.

전원을 끄고 모듈의 **아날로그 출력을 P0**에 연결합니다. 전원·GND는 모듈과 쉴드 설명서를 따릅니다. 마이크로비트 내장 밝기 센서가 아닌 외부 센서를 읽으며, 커넥터 표시에서 아날로그 출력 신호를 확인합니다.

## 프로그램

새 프로젝트에서 이 예제만 사용합니다. 실행 부하를 제외하면 약 0.5초마다 한 번 측정합니다.

```blocks
basic.forever(function () {
    // 아날로그 입력 P0에 연결한 밝기 모듈을 읽습니다.
    let light = ezmaker.readLightRaw(EZMakerAnalogPin.P0)
    // 숫자를 기록하고 매번 같은 눈금으로 표시합니다.
    serial.writeValue("light_raw", light)
    led.plotBarGraph(light, 1023)
    basic.pause(500)
})
```

## 관찰과 기록

1. 보드에 내려받고 LED 막대를 관찰합니다. 숫자는 MakeCode의 연결된 시리얼 콘솔에서 `light_raw`를 확인합니다.
2. 센서를 고정하고 실내 조명에서 세 번 기록합니다.
3. 케이블을 움직이지 않고 센서를 가린 뒤 세 번 기록합니다.
4. 가림을 없애고 빛의 조건을 바꾸어 세 번 기록합니다.
5. 이 모듈에서는 밝아질 때 수치가 커지는지 작아지는지 비교합니다.

| 조건 | 첫 번째 값 | 두 번째 값 | 세 번째 값 | 관찰 내용 |
|---|---|---|---|---|
| 실내 조명 | | | | |
| 가린 상태 | | | | |
| 빛의 조건 변경 | | | | |

예상 결과: 값은 0~1023 범위이며 정상적으로 연결한 모듈은 빛 변화에 반응합니다. LED 막대는 수치가 커질수록 커집니다. 밝아지면 출력도 커질 것이라고 미리 단정하지 말고 사용 중인 모듈에서 관찰합니다. 숫자는 ADC 값이며 조도(lux)가 아닙니다.

## 질문과 확장

- 한 번이 아닌 세 번 측정하는 이유는 무엇인가요? 빛 외에 바뀐 조건이 있나요?
- 그래프의 최댓값을 1023으로 고정하면 어떤 비교가 쉬워지나요?
- `readLightRaw`를 `readLightPercentage`로, 그래프 최댓값을 100으로 바꾸어 봅니다. 백분율은 ADC를 환산한 값이며 교정된 조도는 아닙니다.
- 기록값에서 기준을 정해 밝음·어두움 표시기를 설계합니다. 비교 방향과 기준 선택 이유를 설명합니다.

## 예상과 다를 때

값이 고정되면 모듈 설명서와 P0 신호·케이블·전원·GND를 대조합니다. 값이 흔들리면 조명·센서 위치·접촉 상태부터 비교합니다. 시뮬레이터는 외부 센서를 재현하지 않으므로 실제 보드에서 관찰합니다.
